# Ideas de IA para udesa.edu.ar

Página estática que presenta seis propuestas de inteligencia artificial, cada una con un video que se reproduce paso a paso.

- Abrir `index.html` en el navegador, o servir la carpeta con `npx serve .`
  (el servidor de Python no soporta Range y el video no puede saltar al inicio de cada paso).
- Contenido (ideas, pasos, tiempos, beneficios): `ideas.js`.
- Videos y pósters: `videos/idea-N.mp4` y `videos/idea-N.jpg`.

Atajos: ← → cambiar de paso · Espacio repetir · F pantalla completa · C video completo · M silencio · T texto (en pantalla completa).
